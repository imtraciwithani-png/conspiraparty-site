Privacy Policy

Last updated: October 20, 2026

This policy covers the Conspiraparty phone party game (Android app and web version at conspiraparty-game.onrender.com) and www.conspiraparty.com, run by Traci Anderson ("we").

What the game collects

  • Cover name you type to join a room.
  • Theories and ratings you submit during a round.

We don't require an account, and we don't collect your real name, email, contacts, location, photos or advertising IDs. This information is shown only to players in your room and is kept temporarily in server memory to run the game. It is deleted when the room ends or the server restarts.

How it is used

Only to run the game. We don't sell or share it, and we don't use it for advertising. The game has no ads and no third-party analytics.

Service providers

The game server is hosted by Render (render.com). Like any web server, it may briefly keep standard technical logs such as IP address and request time for security and reliability. Data is sent over encrypted HTTPS.

Website

www.conspiraparty.com is hosted on GitHub Pages and links to Etsy and Amazon (some are affiliate links). Those sites have their own privacy policies.

Children

The game isn't directed to children under 13, and we don't knowingly collect personal information from them.
