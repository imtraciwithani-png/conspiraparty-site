# Conspiraparty redesign art

Web-ready Recraft assets for the conspiraparty.com redesign. See `manifest.json` for the full file list, categories, descriptions, and dimensions.

**Do not use these on main until the redesign preview is approved.**

## Start here

- Homepage hero: `hero/hero-string-board-dark-a-1920.webp` (and `-960.webp`). Dark corkboard sits on the right; leave the cream area on the left for the headline and button. Reference: `_mockups/hero-9-mockup.png`.
- Background tiles: `bg/cipher3-tile-dark.svg` behind the dark hero; `bg/cipher3-tile-light.svg` behind cream product sections. PNG fallbacks are in the same folder. Reference: `_mockups/mockup3-mix.png`.
- Other `hero/*` files are page banners or alternate heroes.
- Spot illustrations: `spot/{name}-800.webp` and `spot/{name}-400.webp`.

## Brand

- Colors: near-black `#111111`, cream `#F3ECDD`, brick red `#C8102E`.
- Fonts: Anton (headlines), Special Elite (typewriter accents), Inter (body). Anton and Special Elite were already in `assets/fonts/`. Inter (`Inter-Regular.ttf`, `Inter-Medium.ttf`, `Inter-SemiBold.ttf`, `Inter-Bold.ttf`) is added in this branch. The live site does not load fonts from Google Fonts.

## Stamps

`stamp-ufo-seal` is the same artwork as `spot/stamp-saucer-seal-*.webp`. Other older stamp names are aliases listed in `manifest.json`.
